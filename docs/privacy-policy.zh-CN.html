Block Bot 隐私政策

最近更新：2026-05-11

English 简体中文

本隐私政策说明 Block Bot 如何处理信息。

1. 我们是谁

Block Bot 是一个浏览器扩展，帮助用户在 x.com / twitter.com 上审查当前可见推文，并在用户确认后，对疑似垃圾账号或机器人账号执行本地屏蔽。

联系方式：support@blockbot-extension.com

2. 我们会访问哪些数据

当用户在 X 页面发起分析时，Block Bot 可能访问：

  • 当前页面可见的推文文本
  • 账号 handle
  • 显示名称
  • 推文链接
  • 个人主页链接

当用户确认执行屏蔽时，Block Bot 可能使用浏览器中现有的 X 登录会话上下文，在本地完成相关操作。

3. 我们如何使用这些数据

我们仅将访问到的数据用于：

  • 分析可见推文并识别疑似垃圾/机器人账号
  • 向用户展示候选账号供复核
  • 在 X 上执行用户确认后的本地屏蔽操作
  • 保存本地扩展配置、队列状态和临时分析缓存

4. 数据共享与第三方

当前版本的 Block Bot 不运营自有分析后端。

若用户启用分析，候选数据将直接从浏览器发送到用户配置的第三方模型服务商，例如 Google Gemini、OpenAI、Anthropic、DeepSeek、Qwen、xAI、OpenRouter、Groq、Mistral AI、Together AI、SiliconFlow、Moonshot、智谱 GLM、火山方舟 Doubao，或其他用户配置的 OpenAI 兼容端点。上述服务商将依据其各自条款与隐私政策处理数据。

5. 数据存储

Block Bot 在 Chrome 扩展存储中本地保存以下信息：

  • 模型服务商选择
  • API 端点配置
  • 用户输入的 API Key
  • 临时分析结果
  • 屏蔽队列状态

默认保留策略：

  • 分析缓存为临时数据，用户可随时清理
  • 服务商配置会保留，直到用户修改配置或卸载扩展
  • 队列状态用于任务连续性，删除扩展存储后会被移除

6. 数据安全

  • 发送到第三方模型服务的数据通过 HTTPS 传输。
  • Block Bot 不会主动将本地存储配置发送到 Block Bot 自有服务器。

7. 有限使用承诺

  • 我们不会出售用户数据。
  • 我们不会将用户数据用于广告投放。
  • 我们不会将用户数据转交给数据经纪商。
  • 我们仅将数据用于上述用户可见功能。

8. 用户控制

用户可自行决定是否：

  • 发起分析
  • 选择模型服务商
  • 填写 API Key
  • 确认要屏蔽的账号

用户可随时卸载扩展，并可通过 Chrome 扩展管理清理扩展数据。

9. 后台标签页行为

为了更可靠地完成部分用户确认后的屏蔽任务，Block Bot 可能临时打开或复用一个后台 X 页面，并在该页面执行本地操作。

10. 隐私政策变更

我们可能不定期更新本隐私政策。页面顶部显示的日期为最近更新时间。
